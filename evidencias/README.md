
# 📋 Evidências de Gerenciamento

Esta pasta contém as evidências de planejamento e gerenciamento do projeto FitControl utilizando a ferramenta Trello.

## Organização do Quadro

O quadro Trello foi estruturado em três listas principais:

### Backlog
Contém todas as atividades planejadas para o desenvolvimento do projeto.

### Em Andamento
Contém as atividades que estavam sendo executadas pela equipe.

### Concluído
Contém as atividades finalizadas e validadas.
