# Diagramas UML - FitControl

Esta pasta reúne os diagramas UML desenvolvidos para o projeto **FitControl**, sistema de gerenciamento de academia criado para a disciplina de Engenharia de Software.

## Objetivo

Os diagramas têm como finalidade representar visualmente a estrutura, o comportamento e os processos do sistema, auxiliando na análise, documentação e desenvolvimento da solução.

## Diagramas Disponíveis

### Diagrama de Casos de Uso
Representa as funcionalidades do sistema e a interação dos atores (Aluno, Recepcionista, Instrutor e Proprietário) com essas funcionalidades.

### Diagrama de Atividade
Apresenta o fluxo de execução dos processos do sistema, demonstrando as etapas realizadas pelos usuários e pelo sistema.

### Diagrama de Sequência
Representa a troca de mensagens entre os elementos do sistema durante a execução de um processo, como a validação de acesso do aluno à academia.

### Diagrama de Estado
Demonstra o ciclo de vida da matrícula de um aluno, incluindo estados como pendente, ativa, suspensa e inativa.

### Diagrama de Classes
Representa a estrutura estática do sistema, incluindo classes, atributos, métodos e relacionamentos entre as entidades.

## Ferramenta Utilizada

Os diagramas foram desenvolvidos utilizando a ferramenta **Draw.io (diagrams.net)**.
