# Arquitetura do Sistema FitControl

## Padrão Arquitetural

O sistema utiliza a arquitetura MVC (Model-View-Controller).

## Model

Responsável pelo armazenamento e manipulação dos dados.

### Classes

- Usuario
- Aluno
- Plano
- Mensalidade
- Pagamento
- FichaTreino
- Exercicio
- Acesso
- Catraca

## Controller

Responsável pelas regras de negócio.

### Controllers

- UsuarioController
- AlunoController
- PlanoController
- PagamentoController
- FichaTreinoController
- AcessoController

## View

Responsável pela interface do sistema.

### Telas

- Login
- Dashboard
- Cadastro de Aluno
- Planos.
- Pagamentos
- Ficha de Treino
- Relatórios

## Banco de Dados

MySQL
